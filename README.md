## Дані й припущення

У блоці 1 наведено початковий розрахунок за методичкою та виправлений:
крайні групи охоплюють хвости нормального розподілу, останні дві групи
об'єднані через очікувану частоту менше 5. Для семи груп df = 7−1−2 = 4.
Параметри 112,5 і 21,4 використано як надані оцінки з цієї вибірки.
Невідхилення H₀ не доводить нормальність.

Для A/B і дата-центрів використано задані середні, виправлені стандартні
відхилення та обсяги. Основний двосторонній t-тест передбачає незалежність,
нормальність і рівні генеральні дисперсії; додатково виводиться p-value Велча.
Дані для цих тестів повторно не генеруються.

Для парної регресії методичка задає лише n=50 та зміст X і Y.
Прийнято навчальну модель X∼U(20,90), Y=10+0,5X+ε, ε∼N(0,4²), seed=42.
Це окрема синтетична вибірка, вона не відтворює характеристики Redis A/B.

У блоці 3 точно виконано модель методички: n=100, X₁∼U(20,90),
X₂∼U(5,50), Y=10+0,5X₁+1,2X₂+ε, ε∼N(0,4²), seed=43.
Генерації X₁, X₂ та шуму незалежні. X₂ моделюється неперервно, як задано
рівномірним законом у методичці. Виконано ANOVA регресії та перевірку
H₀: β₁=β₂=0. Результати стосуються навчальної моделі.
